# SVG Motion Library

The studio's browser-safe motion layer is built from reusable SVG primitives.

Available primitives:

- `AnimatedLine`
- `RoutePath`
- `LocationPin`
- `LabelChip`
- `ProgressRing`
- `Arrow`
- `MotionGrid`
- `CounterText`
- `RevealRect`
- `PhotoMask`
- `KineticWords`
- timing helpers `progress01` and `spring01`

New reusable scene types should compose these primitives before introducing custom per-project drawing code.
