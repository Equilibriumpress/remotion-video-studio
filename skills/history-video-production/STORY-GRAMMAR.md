# History grammar

Hook → intellectual origin → early optimism → obstacles → revival → defining milestone → modern breakthrough → implications → open conclusion.

For 60 seconds, prefer 10–12 shots of 4–6 seconds. Reserve a longer hold for key visual changes. Include year/date titles for landmark events and avoid compressing causal history into exaggerated one-cause explanations. If a factual claim is disputed, qualify it in on-screen text and editorial notes.
