# ChatGPT History Video Producer

ChatGPT researches, writes, illustrates, times and commits each production. GitHub stores versioned project and figures. Pages only previews and exports; no director UI.

1. Check dates and claims against trustworthy primary sources; keep sources and uncertainty in editorial review.
2. Build a 60-second script with distinct narrative beats: question, origin, breakthrough, tension, renaissance, modern impact, closing thought.
3. Assign an illustration to each scene; use cut-paper figure modules and normalized element geometry; avoid recycling the same full composition.
4. Connect recurring visual motifs with keyed `handoff` points; set coordinates of adjacent scenes to match and avoid visible jumps.
5. Author captions and spoken narration separately. Scene subtitles are not timed captions. Procedural audio is instrumental, not speech.
6. Review representative rendered frames and audio, run build validations, and export/play MP4 in Chromium before claiming complete acceptance.
7. Keep attribution and original code in repository; do not copy upstream proprietary examples.
