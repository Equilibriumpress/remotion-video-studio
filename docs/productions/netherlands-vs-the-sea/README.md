# The Netherlands vs. The Sea — production notes

Original 45-second vertical Remotion SVG illustration film.

**Shots:** storm wave (7s), simplified land/sea-level cross-section (9s), schematic impeller pumping water (9s), stylized closing storm barrier (10s), conceptual Netherlands map finale (10s). 30 fps / 1350 frames.

**Art direction:** midnight blue, sea teal, sand, warm copper details. Film is a new set of dedicated SVG compositions, not the Kyoto template.

**Important factual cautions:** Not all of the Netherlands lies below sea level. The polder view is conceptual, not a surveyed elevation profile. The animated closure is a simplified schematic and must not be represented as a faithful Maeslantkering engineering simulation. The final map is stylized, not precise GIS coast geometry. A premium factual release should replace these with validated Delta Works geometries and an accurate sourced map, and have captions editorially fact-checked.

**Visual QA:** inspect five shots at 0%, 50% and 95%, check safe captions on TikTok, verify browser sound, export Chromium MP4 and play final 45 seconds. The existing Canvas QA cannot inspect SVG DOM pixels, so end-to-end render QA remains essential.

**Workflow:** ChatGPT authors illustrations; GitHub stores code; Pages plays and renders. No external video assets and no server-side encoding.
